# 🍉 Fruit Slash

**Turn your webcam into a blade and your hands into weapons! 🖐️⚔️**

Fruit Slash is a fun, interactive **webcam-based fruit-slicing game** where you use your hand movements to slash flying fruits in real time. No keyboard, no controller — just move your hands, slice the fruits, and chase the highest score! 💥

## 🎮 Features

* 🖐️ **Hand-controlled gameplay** using your webcam
* 🍉 Multiple fruits flying across the screen
* 🔪 Real-time slicing using hand movements
* 🏆 Score tracking
* ⚡ Fast-paced and responsive gameplay
* 📷 Live camera interaction
* 🎨 Colorful and interactive game interface
* 💻 Runs directly in your web browser
* 👥 Supports movement with both hands

## 🕹️ How to Play

1. Open the game in a compatible web browser.
2. Allow **camera access** when prompted.
3. Click **Start Game**.
4. Place your hands in front of the camera.
5. Move your fingers/hands across the fruits to slice them.
6. Keep slicing and try to achieve the highest score! 🍉🔥

## 🛠️ Technologies Used

* **HTML** — Game structure
* **CSS** — Interface and visual styling
* **JavaScript** — Game logic and interactions
* **Webcam / Camera API** — Real-time camera input
* **Hand Tracking / Computer Vision** — Detecting hand movements

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/fruit-slash.git
```

Open the project folder:

```bash
cd fruit-slash
```

Then open `index.html` in your browser.

For the best experience, use **Google Chrome or Microsoft Edge** and allow camera permissions.
